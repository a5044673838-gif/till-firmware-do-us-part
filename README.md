One wedding vow a robot says at its own wedding, written by a deterministic
Python program (standard library only, no network). The vow is one sentence,
under 200 characters: a machine promising to love its human in Wi-Fi and in
airplane mode, until its firmware gives out and its battery runs dry. The
program writes the vow to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
